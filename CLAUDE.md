# LAMP — мультитенантная ATS

Проект ведёт человек без опыта разработки. Все объяснения — на русском, по шагам,
без предположений о знании терминологии. Не переходить к следующему этапу,
пока текущий не работает.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS 4, палитра в `src/app/globals.css`
- Prisma 7.10.0 (зафиксировано точно: тег `latest` указывает на нестабильный 8.0-rc)
- PostgreSQL в Neon (Frankfurt), подключение через `@prisma/adapter-pg`
- Проверка данных — zod, иконки — lucide-react

## Команды

- `npm run dev` — сервер разработки на http://localhost:3000
- `npm run db:migrate` — применить изменения схемы к базе
- `npm run db:studio` — визуальный просмотр базы
- `npm run db:check` — проверка подключения и количества записей

## Правила проекта

1. Изоляция компаний: любой запрос к данным обязан фильтроваться по `companyId`
   из сессии. Никогда не доверять `companyId` из формы или адреса страницы.
2. Права проверяются на сервере, а не только скрытием кнопок в интерфейсе.
3. Пароли — только через `src/lib/password.ts` (scrypt), в базе лежит отпечаток.
4. Сессии — `src/lib/session.ts`, в cookie случайный ключ, в базе его sha256.
5. Важные действия пишутся в `AuditLog` через `src/lib/audit.ts`.
6. Идентификаторы — cuid, не последовательные номера.

## Особенности окружения

- Windows. В shell этой сессии PATH может не содержать Node.js —
  используйте `export PATH="/c/Program Files/nodejs:$PATH"`.
- Документация Next.js 16 лежит локально: `node_modules/next/dist/docs/`.
